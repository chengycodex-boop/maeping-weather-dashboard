# ผลค้นสถานีสนับสนุนรอบอุทยานแม่ปิง — 23 สิงหาคม 2569

## ผลลัพธ์

ใช้ ThaiWater public JSON `rain_24h` เป็น station snapshot และใช้แนวเขต OpenStreetMap relation 6004000 เป็นขอบเขตชั่วคราว พบสถานีที่มีพิกัดอยู่ในระยะไม่เกิน 75 กม. จาก polygon จำนวน 317 สถานี

| ระยะจากแนวเขต | จำนวน |
|---|---:|
| อยู่ภายใน polygon | 2 |
| นอกแนวเขตไม่เกิน 25 กม. | 70 |
| มากกว่า 25 ถึง 75 กม. | 245 |

แยกตามหน่วยงานใน payload: ทน. 175, พพภ 59, สสน. 47, ปภ. 20, ชป. 11, อต. 4 และ กฟผ. 1 สถานี ผลนี้เป็น inventory ไม่ใช่จำนวนสถานีที่ผ่าน QC และสถานีหลายแห่งอาจซ้ำพื้นที่หรือไม่มีตัวแปรที่ต้องการ

## หลักฐานใหม่ที่กระทบ Master 13 จุด

1. `DNP089` ชื่อที่ทำการอุทยานแห่งชาติแม่ปิง พิกัด 17.670780, 98.870050 อยู่ห่างพิกัด HQ master ประมาณ 43 เมตร และมีทั้งฝนกับอุณหภูมิครบในช่วงทดสอบ จึงควรเป็น ground-truth candidate ลำดับแรก แต่ต้องเก็บ sensor location แยกจาก reporting location
2. `DNP088` ระบุชื่อหน่วยพิทักษ์อุทยานแห่งชาติแม่ปิงที่ มป.7 (ถ้ำหม้อ) พิกัด 17.817820, 98.751040 ตรงกับพิกัด master เดิมเกือบพอดี และมีฝน/อุณหภูมิครบ อย่างไรก็ดี ข้อมูลนี้ยืนยันชื่อ “ถ้ำหม้อ” ไม่ใช่ “น้ำห่อ” จึงเพิ่มน้ำหนักให้ source conflict แต่ยังไม่ปิด issue จนกว่าจะมีคำยืนยันจาก DNP
3. `STN1266` บ้านหนองเชียงคา พิกัด 17.345768, 99.050204 ช่วยยืนยัน area anchor ของ มป.11 แต่ยังไม่ใช่พิกัดตัวหน่วยดอยขุนเม่น
4. Google Maps short link สองแหล่ง resolve ไป Place ID จุดชมพระอาทิตย์ขึ้นผาแดงหลวงเดียวกันที่ 17.4901904, 98.7794662 จึงใช้เป็น area anchor ของ มป.9 ได้ แต่ไม่ถือเป็นพิกัดอาคารหน่วย

## ข้อจำกัดที่ต้องไม่มองข้าม

- ThaiWater เป็นผู้รวบรวมข้อมูลหลายหน่วยงาน ชื่อหน่วยงานใน payload ต้องเก็บควบคู่กับ station ID
- การมี record ใน `rain_24h` ไม่รับประกันว่ากราฟอุณหภูมิหรือประวัติฝนจะมีค่า
- timestamp ใน payload ไม่มี timezone offset ต้องตรวจ convention กับผู้ให้ข้อมูลก่อนรวมกับ forecast verification
- ระยะจากอุทยานคำนวณจากแนวเขต OSM ซึ่งเป็นแหล่งรอง ต้องรันใหม่เมื่อได้ polygon ทางการจาก DNP
- ควรตรวจคู่สถานีที่อยู่ใกล้กันมากเพื่อไม่ให้น้ำหนักพื้นที่ซ้ำ และไม่ควรให้ 317 สถานีมีน้ำหนักเท่ากัน
- แหล่งสาธารณะของถ้ำยางวี/น้ำตกก้อน้อยให้พิกัดขัดกันหลายกิโลเมตร จึงใช้พิกัด มป.12 ที่ผู้ใช้ให้มาเป็น area anchor ความเชื่อมั่นต่ำเท่านั้น และต้องแสดงคำเตือนว่าไม่ใช่พิกัดตัวหน่วย

## ขั้นถัดไป

1. นำเฉพาะ shortlist ที่ผ่าน QC เข้า `locations` เป็น support sensor locations
2. ดึงฝนรายชั่วโมงและอุณหภูมิของ priority 1 ทุกชั่วโมงแบบ append-only
3. วัด completeness, freshness, stuck-at-zero, spike, range และความสอดคล้องกับสถานีข้างเคียงทุกวัน
4. ขอ DNP ยืนยันชื่อ มป.7 และพิกัดตัวอาคาร มป.8, มป.9, มป.12; ระหว่างนี้ มป.8 (17.585, 98.745) และ มป.12 (17.518, 98.788) ใช้เป็น area anchor ความเชื่อมั่นต่ำเท่านั้น
5. ขยาย QC จาก shortlist ไปยัง 70 สถานีใน buffer 25 กม. ก่อนพิจารณา buffer 75 กม.
