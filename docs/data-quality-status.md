# สถานะคุณภาพข้อมูล ณ 23 สิงหาคม 2569

## Grain และขอบเขต

- จุดรายงานหลัก 13 จุด: HQ และ มป.1–มป.12
- ขอบเขตอุทยานระยะแรก: OpenStreetMap relation 6004000 (แหล่งรอง)
- ขอบเขตค้นสถานีสนับสนุน: buffer 25 และ 75 กม. รอบพื้นที่อุทยาน

## ผลตรวจ Master 13 จุด

| ระดับ | จำนวน | ความหมาย |
|---|---:|---|
| ใช้เป็นพิกัดที่มีเอกสารรองรับเบื้องต้น | 1 | HQ; ยังต้องตรวจชนิดเซนเซอร์และเลขหน้าเอกสาร |
| พิกัดมีหลักฐานแต่ชื่อแหล่งขัดแย้ง | 1 | มป.7 น้ำห่อ/ถ้ำหม้อ; ห้ามใช้เป็น ground truth จนกว่าจะยืนยัน |
| Area anchor | 11 | ใช้สกัดค่ากริดของพื้นที่ได้ แต่ห้ามเรียกสถานีกระบอกวัด; มป.8 และ มป.12 เป็น spatial approximation ความเชื่อมั่นต่ำ |
| ไม่มีพิกัด | 0 | แสดงครบ 13 จุดแล้ว แต่ยังไม่เท่ากับยืนยันพิกัดตัวอาคารครบ |

ระบบยังคงเปิด issue สำหรับ area anchor ทุกจุด: มป.8 และ มป.12 เปลี่ยนจาก `missing_coordinate` เป็น `unverified_spatial_approximation` เพื่อให้ขึ้นแผนที่ได้โดยไม่อ้างว่าเป็นพิกัดตัวหน่วย

เมื่อรวมทะเบียนสถานีสนับสนุน ฐานข้อมูลมี issue เปิด 14 รายการ: 12 รายการของ Master ข้างต้น และ Medium อีก 2 รายการสำหรับสถานีที่พักไว้เพราะ completeness ต่ำ/ไม่มีประวัติเพียงพอ

## ความเสี่ยงที่มีผลต่อ Dashboard

1. **High — พิกัดตัวหน่วยยังยืนยันไม่ครบ:** มีจุดอ้างอิงครบ 13 จุดแล้ว แต่ยังสร้างค่ารายจุดแบบอ้างว่าเป็น station measurement ไม่ได้
2. **High — ชื่อ มป.7 ขัดแย้ง:** อาจเกิดการจับคู่ค่าฝนกับหน่วยผิดแห่ง
3. **Medium — point/grid mismatch:** พิกัดพื้นที่อ้างอิงต้องแสดงเป็น `Area Estimate`
4. **Medium — ขอบเขตอุทยานยังเป็นแหล่งรอง:** ใช้พัฒนาได้ แต่ buffer และพื้นที่เฉลี่ยควรคำนวณใหม่เมื่อได้แนวเขต DNP
5. **Medium — coverage ต่างกันรายตัวแปร:** ThaiWater public JSON ใช้งานได้และมีสถานีฝนใกล้พื้นที่จริง แต่บางสถานีไม่มีอุณหภูมิแม้มีฝน จึงต้องตรวจ availability แยกตัวแปร
6. **Medium — เวลา API ไม่มี offset:** ค่า `rainfall_datetime` และกราฟอากาศไม่มี timezone offset ใน payload ต้องยืนยัน convention ก่อนรวมกับ forecast

## ผลค้นสถานีสนับสนุนรอบแรก

- ยืนยัน endpoint ฝนปัจจุบัน `rain_24h` พร้อม station ID, code, agency, พิกัด และเวลาอัปเดต
- ยืนยันกราฟฝนรายชั่วโมง `rain_24h_graph` และฝนรายวันย้อนหลัง `rain_yesterday_graph`
- ยืนยันกราฟอุณหภูมิ `temperature_graph`; ต้องนับ non-null รายสถานี ไม่อนุมานจากการมีสถานีฝน
- พบสถานีใกล้จุดรายงานที่มีประโยชน์ เช่น บ้านก้อทุ่ง (`STN1161`), อาคารเทศบาลตำบลก้อ (`TJ85`), บ้านดอยเต่าใต้ (`STN1540`) และบ้านหนองเชียงคา (`STN1266`)
- ระยะ 25/75 กม. ยังอิงแนวเขต OpenStreetMap relation 6004000 จึงเป็นผลคัดกรองเบื้องต้นจนกว่าจะได้แนวเขต DNP
- ผลรัน 23 สิงหาคม 2569 พบ 317 สถานีภายใน 75 กม.: ใน polygon 2, buffer 25 กม. 70 และ buffer 25–75 กม. 245
- shortlist ที่ผ่านเบื้องต้นสำหรับฝนและอุณหภูมิ: DNP089, DNP088, PIN011 และสถานี TMD เขื่อนภูมิพล 48377; รายละเอียดอยู่ใน `data/support_station_shortlist.csv`
- พิกัดจุดชมวิวผาแดงหลวงจาก Google Maps Place 17.4901904, 98.7794662 ทำให้ มป.9 มี area anchor แล้ว แต่ยังไม่ใช่ตำแหน่งอาคารหน่วย
- มป.8 ใช้ 17.585, 98.745 และ มป.12 ใช้ 17.518, 98.788 เป็น area anchor ความเชื่อมั่นต่ำตาม spatial approximation ที่ผู้ใช้ให้มา ทั้งสองจุดอยู่ในแนวเขต OSM ชั่วคราว แต่ยังไม่ใช่พิกัดตัวอาคารหน่วย
- ทะเบียนถ้ำในรายงาน TSRI ให้ UTM ของถ้ำยางวีซึ่งแปลงได้ประมาณ 17.5204, 98.7694 อยู่ในบริเวณใกล้เคียงกับ anchor มป.12 ขณะที่ OSM มี cave entrance อีกจุดที่ 17.48833, 98.87091 จึงต้องคงสถานะรอยืนยันภาคสนาม

## สิ่งที่พร้อมใช้

- Schema แยก observation, forecast, source, location, evidence และ quality issue
- เก็บ forecast แบบ append-only ตาม model run/issued time/valid time/lead time
- Metrics ฝนและอุณหภูมิพร้อมชุดทดสอบ
- Source registry แยก primary/secondary/tertiary และระบุ latency/ข้อจำกัด
- ตัวเชื่อม ThaiWater เก็บ observation 1,027 แถวจาก 7 สถานีปฏิบัติการใน snapshot ล่าสุด โดยแยกฝน 60/1,440 นาทีและรอบอุณหภูมิ 60/180 นาที
- ตัวเชื่อม Open-Meteo รอบล่าสุดเก็บ forecast baseline 16,416 แถวสำหรับ 11 จุดรายงานและ 7 พิกัดเซนเซอร์ปฏิบัติการ ถึง 29 สิงหาคม 2569
- Dashboard แผนที่ local แสดงค่าจริง/ค่าพยากรณ์, provenance และข้อจำกัด โดยไม่มีการเติมค่าจุดที่ข้อมูลหายเป็นศูนย์
- ฝนสะสม 24 ชั่วโมงคำนวณจากสถานี ThaiWater ที่มีข้อมูลรายชั่วโมงอย่างน้อย 18/24 ชั่วโมง แล้วประมาณเชิงพื้นที่ด้วย IDW พร้อมแสดง coverage และช่วงความไม่แน่นอน; ไม่ใช้ forecast ย้อนแทนค่าฝนที่ผ่านมา
- ระบบ verification สร้าง 70 กลุ่ม `location × variable × lead bucket`; snapshot แรกมี 0 คู่และแสดง `no_pairs` ทั้งหมดอย่างโปร่งใส
- เพิ่มสถานีฝน Priority 2: STN0370, STN1161 และ STN1540 มีฝนรายวัน 29/30, 28/30 และ 29/30 วันตามลำดับ และไม่มี temperature rows ตาม capability
- แก้ช่วง `temperature_graph` ให้ขอถึงวันถัดไป ทำให้ได้ค่าของวันปัจจุบันถึง 15:00 แทนการหยุดที่ 00:00
- Quality gate ล่าสุด: critical 0, warning 1, suspect 0, duplicate key 0, foreign-key issue 0 และอุณหภูมิผิด capability 0 คำเตือนหนึ่งรายการคือ TMD QPE latest เก่า 1,021 ชั่วโมงและถูก freshness gate ตัดออก
- Technical readiness 93.5%; evidence maturity 32.5%; operational readiness 69.1% โดยแสดงแยกกันบน Dashboard
- Calibration pipeline สร้างครบ 70 กลุ่ม แต่ `ready=0` และไม่เผย parameter เพราะยังไม่มี sample day/เหตุการณ์ฝนครบ gate

## เงื่อนไขก่อนเปิด Accuracy Score

- มี forecast–observation pairs อย่างน้อย 60–90 วัน
- มีคู่ข้อมูลเพียงพอในแต่ละ lead bucket และแต่ละฤดูกาล
- ตรวจหน่วย เวลา timezone และ period accumulation ตรงกัน
- แยกคะแนน point, area และ grid
- ไม่รวมข้อมูล `suspect`, `missing` หรือพิกัด source conflict เป็น ground truth
